## 📖 About
This repository provides a fully automated, distro-agnostic workflow to compile the `shadps4` emulator (via the [bigmak94/AstroQuest](https://github.com/bigmak94/AstroQuest) project) and package it into a portable Linux AppImage. 

It includes three scripts designed to work together:
1. `build-everything.sh`: The master script that checks dependencies, clones the source, compiles `shadps4`, and triggers the AppImage build.
2. `build-appimage.sh`: Collects dependencies, sets up the AppDir, and packages everything using `linuxdeploy` and `appimagetool`.
3. `astroquest-linux-v2.sh`: A robust, GUI/TTY-friendly launcher that handles settings, game discovery, `.pkg` unpacking, and OpenXR environment setup.

## 🚀 How to Compile/Where to Download

### 🛠️ Prerequisites
Before building, ensure you have the necessary development tools and libraries installed. **The master script will prompt you with the exact command for your distro, but for reference:**

- **Debian / Ubuntu**:  
  `sudo apt install git cmake ninja-build clang patchelf binutils desktop-file-utils file wget python3 pkg-config libx11-dev libwayland-dev libasound2-dev libpulse-dev libvulkan-dev libudev-dev libevdev-dev libhidapi-dev libssl-dev zlib1g-dev libpng-dev libcurl4-openssl-dev`
- **Fedora**:  
  `sudo dnf install git cmake ninja-build clang patchelf binutils desktop-file-utils file wget python3 pkgconf-pkg-config libX11-devel wayland-devel alsa-lib-devel pulseaudio-libs-devel vulkan-loader-devel systemd-devel libevdev-devel hidapi-devel openssl-devel zlib-devel libpng-devel libcurl-devel`
- **Arch Linux**:  
  `sudo pacman -S git cmake ninja clang patchelf binutils desktop-file-utils file wget python pkgconf libx11 wayland alsa-lib pulseaudio vulkan-headers systemd-libs libevdev hidapi openssl zlib libpng curl`

### Option A: Standard Build (AppImage *without* the game)
This is the recommended method for sharing or publishing. The resulting AppImage will be small and will prompt you to select your game folder on first launch.
A pre-built, **gameless** AppImage is available in the [Releases](../../releases) section of this repository for you to download. 

**⚠️ Note on Updates:** 
Because I am too lazy to set up automatic GitHub Actions builds, the pre-built AppImage might not be updated to the latest `bigmak94/AstroQuest` version.

    ./build-everything.sh

### Option B: Bundled Build (AppImage *with* the game inside)
If you are building this strictly for **your own personal use**, you can bundle the game directly into the AppImage. 

**💡 The Space-Saving Advantage:**  
A raw dumped game folder (`CUSA12392`) needed to run the game, takes up about **~13 GB** of disk space. However, when you pass the `GAME_DIR` variable to the build script, `build-appimage.sh` uses `zstd` compression (`--comp zstd`). This compresses the 13 GB of game data down to roughly **~6.6 GB** inside the final AppImage. This saves nearly 50% of disk space while maintaining lightning-fast decompression on the fly during gameplay!

> *Yes, I know that you need to download a ton of dependencies and wait for it to compile, wasting time and more disk space, but it's worth it afterwards. I also know that you'll probably have a .pkg and you have to decompress it just to recompress it afterwards, but the emulator can only run raw folders so... yeah.*

    # Follow steps 1 and 2 from above
    # Run the script and provide the path to your game folder when prompted
    # (The folder must contain 'eboot.bin')
    ./build-everything.sh
    # > Path to game directory: /path/to/your/CUSA12392

*Alternatively, you can pass it via environment variable:*  
`GAME_DIR=/path/to/your/CUSA12392 ./build-everything.sh`

## 🎮 How to Play

1. **Set up your OpenXR Runtime**: Ensure you have an OpenXR runtime installed and set as active (e.g., **WiVRn** or **Monado**). The launcher will warn you if none is detected.
2. **Connect your Controller**: Plug in or pair your PS5 DualSense (or DualShock 4) to your **PC**, *not* the headset.
  > *Note: Hand tracking for controller position has not yet been tested. This build was specifically tested on a Pico 4 Enterprise using Pico 4 controllers and WiVRn.*
3. **Run the AppImage**:

        chmod +x AstroQuest-x86_64.AppImage
        ./AstroQuest-x86_64.AppImage

4. **First Launch**: If you didn't bundle the game, a GUI or terminal prompt will ask you to select the folder containing your `eboot.bin` or `.pkg` file. If you provide a `.pkg`, the launcher will automatically unpack it for you.
5. **Settings Menu**: A settings window will appear allowing you to configure resolution, framerate, FOV, and desktop spectator view. These settings are saved to `~/.config/AstroQuest/settings.txt`.

## ⚠️ Troubleshooting
- **"No OpenXR runtime found"**: The game will still launch, but only in flat desktop mode. Install and configure [WiVRn](https://github.com/WiVRn/WiVRn) or Monado for VR.
- If your system complains about FUSE, run it with: `APPIMAGE_EXTRACT_AND_RUN=1 ./AstroQuest-x86_64.AppImage (this negates the benefits of the Bundled Build, just fix your system instead)
